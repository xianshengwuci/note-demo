# 我的笔记分类小工具

一个使用 Python 和 Gradio 制作的本地网页练习项目。它按每行开头的标签整理笔记，不调用 AI，也不需要 API Key。

## 功能

- 将笔记分为“已完成”“待确认”“下一步”和“未分类”
- 每行一条笔记
- 支持以下开头：
  - `已完成：` 或 `完成：`
  - `待确认：` 或 `疑问：`
  - `下一步：` 或 `待办：`
- 没有匹配标签的内容会放进“未分类”

## 环境要求

- Python 3.13
- Gradio

## 安装 Gradio

在 Windows 命令提示符中运行：
